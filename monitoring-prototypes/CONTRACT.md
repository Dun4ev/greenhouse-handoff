# Общий контракт прототипов, только этап 1

Каждый вариант экспортирует `render(scenario)` из assets/a.js, b.js или c.js.
Возвращает HTML-строку для содержимого main. Заголовок, переключатель сценариев
и ссылки A/B/C создает ведущий агент. Стили варианта лежат в assets/a.css и т. д.
Не читать и не копировать оформление старых HTML. Только мониторинг, без команд.

Сценарий: `{id, nowLabel: '14:32', zones, events}`.
Зона: `{id: 1|2, name, outlets: 3|6, stale: boolean, status: 'idle'|'watering'|'unknown', statusLabel, lastSeen: '14:31:50', ageLabel: '10 с назад', flow: 'Есть поток'|'Нет потока'|'Неизвестно', activeOutlet: number|null, elapsed: '8 мин'|null}`.
Событие: `{time, zone: 1|2, text, kind: 'info'|'warning'}`. Уже отсортированы от новых к старым.
Норма: обе зоны свежие, полив не идет. Второй сценарий: зона 1 поливается,
зона 2 не присылала данные 22 минуты, ее текущий полив и поток неизвестны.
Данные синтетические, время фиксировано. Не выдумывать другие значения.

Общие CSS-переменные: --paper #f5f3ef, --surface #ffffff, --ink #252735,
--muted #626572, --line #dcdde1, --accent #3b477a, --water #354c98,
--warn #903c23, --warn-bg #fff0e8. Шрифт системный sans-serif.
Классы: .eyebrow, .muted, .section-heading, .status, .status--watering,
.status--stale, .time-note, .metric-value. Максимальная ширина оболочки 430px;
при 390px внутренний размер main 358px (отступы 16px).
Статусы всегда текстом. Свежесть каждой зоны видна без раскрытия.
Устаревшие данные не изображать текущими: поток неизвестен, полив неизвестен.
Нет графиков, боковой/нижней навигации приложения, иллюстраций и фиктивных кнопок.
При необходимости details для последнего пакета, но не обязательны.
Крупные показатели, спокойная ясная структура, уникальная для варианта.
Русский текст без буквы е с точками и длинного тире.
